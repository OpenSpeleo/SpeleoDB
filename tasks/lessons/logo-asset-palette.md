# Read the current logo assets before documenting colors

After a user changes or renames logo assets, inspect the current files rather
than carrying forward a previously requested palette. The canonical pair is
`logo-sdb-dark.svg` and `logo-sdb-light.svg`; both use blue `#3852fc`. Their
lettering and icons are white and almost-black grey (`#111111`), respectively.
The earlier pale-blue light-variant choice is superseded.

Use the user's confirmed canonical filenames in documentation and status
updates. Do not distract from a rename with references to superseded assets.
